# Rayen Mhamdi Portfolio

Personal portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Local development

```sh
npm install
npm run dev
```

## Deployment

Push changes to `main` to build and deploy the site to GitHub Pages with the
workflow in `.github/workflows/deploy.yml`. In the repository settings, enable
Pages and select **GitHub Actions** as the build and deployment source.
